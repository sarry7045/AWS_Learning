Benfiets of the Serverles - In Non Serverles the System is continoulsy running and it's has fixed rate, But in Serverles it's not, It only runs and gives response once user hit/invoke the URL, It count the invokes like how many times the URL hit by users.
Scalibility - Now lets suppose 1000 users came on Serverles, so in that situation the Serverles creates the Multiple Copies of that code to handle the multiple Users, means it will run 1000 Diffrent codes in parallel, It called Scale UP and Scale Down.

Duration in Serverles - Suppose any function taking to much time to invoke in that case also it charge on per GB Second.

API Gateway - With the Use of this we can Create URL to hit or invoke that Lamba function. Multiple endpoints conenct with one Single API Gateway and we can Hit with that specific endpoints.
